# TextUtil [![Live Demo](https://img.shields.io/badge/View-Live-green)](https://shree031.github.io/TextUtils-React/)


TextUtil is a simple and responsive React-based text utility app. It allows users to perform various operations on their text such as converting to uppercase/lowercase, capitalizing, removing extra spaces, and more. The app also supports a light/dark theme toggle to enhance accessibility and user experience.

## 🚀 Features

- 🔤 Convert text to **uppercase**, **lowercase**, or **capitalize** each word
- 🧹 Remove extra spaces
- 📋 Copy text to clipboard
- 🧮 Display **word count**, **character count**, and **estimated read time**
- 🌓 **Light/Dark mode** toggle using Bootstrap
- ✅ Responsive UI using Bootstrap 5

## 🛠️ Built With

- [React](https://reactjs.org/) – Frontend library
- [Bootstrap 5](https://getbootstrap.com/) – Styling
- [Icons8](https://icons8.com/) & [Bootstrap Icons](https://icons.getbootstrap.com/) – Icons and visuals

## 🚀 Getting Started

### Prerequisites

- Node.js (>= 14)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/textutil.git
cd textutil

# Install dependencies
npm install

# Run the app
npm start
```

App will run on: `http://localhost:3000`

## 🌙 Theme Toggle

The app includes a theme toggle switch in the navbar:
- Switch between light and dark mode
- Icon adapts to the current theme
- Entire layout updates accordingly
